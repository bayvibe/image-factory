# 图片工厂

图片工厂是一个面向社交内容创作的图片模板工具。当前版本提供 Yes / But 双图模板和调色卡模板，可以快速生成适合小红书等平台分享的 3:4 图片，并支持批量导入、自动分组和一键导出。

公开访问链接：<https://bayvibe.github.io/image-factory/>

## 功能

- 单张模式：上传上下两张图片，生成一张 Yes / But 拼图。
- 调色卡模板：上传一张图片后自动提取主色，生成上半部分色块、下半部分图片的色彩记录卡。
- 文案编辑：调色卡文案可直接点击修改，并内置多种移动端可用的中文字体。
- 批量模式：一次导入多张图片，按模板自动分组批量生成。
- 直接编辑：在画布上拖拽调整图片位置，滚轮或双指缩放裁切。
- 字体切换：内置多种标题字体风格。
- 一键导出：支持单张下载，也支持批量连续下载。
- 固定画幅：输出尺寸为 1080 x 1440，适配 3:4 社交平台图片。

## 本地开发

```bash
npm install
npm run dev
```

打开 <http://localhost:3000> 查看本地页面。

## 构建

```bash
npm run build
```

项目使用 Next.js 静态导出。推送到 `main` 后，GitHub Actions 会自动构建并部署到 GitHub Pages。
